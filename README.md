# QA Automation Portfolio

Portafolio profesional de QA manual y QA Automatizacion de Jessica Villena 

## Objetivo

Demostrar el ciclo completo de aseguramiento de calidad: analisis de requerimientos, diseno y ejecucion de pruebas manuales, gestion de defectos, pruebas de API, automatizacion con Postman y Newman, ejecuacion automatizada y validacion de datos con SQL

## Sistema bajo prueba 

Restful-Booker: API pública de reservas con datos ficticios 

## Estado del proyecto

En construcción. Este repositorio se desarrolla por fases y se actualiza de forma continua
